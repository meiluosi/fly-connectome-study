# 预先登记：TSP v3 —— 转角上下文（状态依赖的边价值）

状态：在任何 v3 测试实例上运行之前登记。冻结文件及哈希见 PREREG_v3.sha256。
动机（来自 v2 的独立审查）：v2 的边签名与 η 高度重合（学到的价值与 −log D 相关 0.85），所以学习器几乎没有新信息，v2 的"连线无效"既不能证明也无法检验。v3 给回路 **η 和信息素都无法表达的信息**：选择下一个城市 j 时，上一个城市 h 造成的转角（h→i→j）。

## 设计
- 转移签名 = (j 在 i 的近邻排名, 距离箱, 互为近邻, i 在 j 的排名, j 的质心箱, 转角箱[7 个角度箱 + "无上一城"])，共 6 个小球（v1 的 5 个静态特征 + 转角，占用小球 52–59）。
- 权重 = τ^α · η^β · exp(κ·V[h,i,j])；回路（MB 真实连线 / MB 随机稀疏 / 线性）在每个实例内从零在线学习（规则同 v2：路线优势减预测价值，同签名取均值）。
- 实现：v3/v3core.py（`run3`；测试 test_v3core.py：无回路时与 v1 `aco_vec` 逐位一致；转角箱正确；路线合法）。
- 臂：ACO（v2 调好的参数）；NOTAU-none（α=0、κ=0，纯 η 采样，v2 审查要求的对照）；ON-real、ON-random（v2 的静态签名在线学习，参数同 v2）；**HAND-turn（手写固定转角惩罚 exp(−γ·(1−cos θ))，不学习；回答"转角上下文本身有没有用"）**；TURN-real、TURN-random、TURN-linear。
- 调参（仅调参实例，种子 8000–8239，每区域 40 个，2 重复）：TURN-k：lr∈{0.03,0.1,0.3} × κ∈{2,4,8,16}；HAND-turn：γ∈{0.1,0.25,0.5,1,2,4,8,16}（第一阶段 γ 落在 0.5 的下边缘，故扩展）。ACO/ON-* 参数沿用 v2 的最终调参结果，不再调。
- 评估：新测试种子 R1 9000–9299、R2 9300–9599、R3 9600–9899（均 300 个；R1/R2/R3 与 v2 定义相同）；每臂 3 个重复；对实例做自助法。
- 判定与 v2 相同（±0.5pp）。**主结论（3 个对比）：TURN-real − ACO，R1、R2、R3，用 99.2% 区间**。其余（TURN-real 对 TURN-random/TURN-linear/HAND-turn/ON-real；HAND-turn、TURN-random、TURN-linear 对 ACO；NOTAU-none 对 ACO）为 95% 区间的描述性结果。

## 预期（运行前写下）
- HAND-turn 若有收益，说明转角上下文本身有用；若 HAND-turn ≈ ACO，则任何学习器都不太可能从中获益。
- TURN-real ≈ TURN-random ≈ TURN-linear（连线无关）；TURN 相对 ACO 的改进不超过 0.5pp。
- 若 TURN-* 优于 ACO 而 HAND-turn 不优于，则"学习上下文价值"本身有用；若 TURN-real 优于 TURN-random，才是第一个连线特异性的证据（我认为不太可能）。
- 已知局限（保留）：调参用的是调参集，学习器继承 ACO 的 α、β、ρ；转角特征仍是手写；转移签名空间很小，学习器与查表几乎等价，因此"稀疏扩展的作用"在此依然很难显现。
