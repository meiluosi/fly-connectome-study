Fix: regenerate RESULTS from the current file, state the edit in DEVIATIONS_v2.md (likely a label fix), and confirm that CON, HEAD, MARG and the verdict rule are unchanged. Until then, "analysis frozen" cannot be claimed.
2. **The signature/learner cannot carry information beyond eta, so the "structure does not matter" null is mostly uninformative about wiring.** Evidence from my probe (R1, 30 tuning instances, tuned ACO 1,8,0.9, 1 rep):
   - Final-run valence: std 0.077, max |V| 0.34, corr(V, -log D) = 0.85. At kappa=8 this is a mild distance re-weighting, essentially eta^beta again.
   - Features (rank, distance bin, mutual-NN, centre-distance bins; fly_heuristic.py:5-12) are static functions of geometry. Only about 530 distinct signatures per instance, and 25 updates per instance.
   - alpha=0 gives 6.03 with no learner and 6.02 and 6.06 with the learner (kappa 8 and 16). So NOTAU-real and NOTAU-linear differ from each other only by noise.
   - Consequence: real, shuffled, random and linear are all "eta + small smooth bias". Equivalence of wirings is expected from the design. It says nothing about whether real wiring would help with informative features (instance-specific edge memory, tour-conditioned state, learning across instances with richer inputs).
3. **NOTAU 5-10pp worse is expected, not a bug.** alpha=0 sets tau^0=1 (v2core.py:59), which removes the only edge-specific memory. kappa and lr are inherited from the alpha=1 tuning (arms.py:35-37), and the learner cannot replace it (item 2). NOTAU is just a beta=8 eta-only sampler: 6.0 for 500 constructions in my probe, the same as 1 iteration of 500 ants (6.04). There is no kappa=0 NOTAU control in the design. Do not read NOTAU as "pheromone beats the learner". It only shows the learner adds no memory. Add the control "NOTAU-none" for the interpretation, at least in RESULTS text.
4. **"ACO is a greedy sampler, so the question is moot" is only half true.** rho=0.9 with tmin=tmax/2n gives about a 100:1 weighting toward the previous iteration's best tour. That is strong exploitation around the incumbent, and it matters. In my probe, ACO is 5.75 vs eta-only 6.03, and rho=0.1 gives 5.91. ISL4 (5 ants per island, no exchange) is 0.6-1.7pp worse than ACO (RESULTS R1-R3). So the pheromone matters; the baseline is hard to beat because it already exploits the instance. The extreme rho (grid edge/physical limit, DEVIATIONS 4) shows the low-budget regime rewards pure intensification, so there is little headroom for a learner that only supplies a smooth prior.
5. **Verdict labels hide small but significant R3 effects.** analysis_v2.py:15 labels "equivalent" whenever the CI is inside the margin. In R3 the headline ★ON-real−ACO is −0.26 [−0.44,−0.07] at 99.4%: the CI excludes 0, which means a likely real improvement below the margin. ON-random−ACO is −0.25 [−0.38,−0.12], ISL4x−ACO −0.33, HET4-real−ACO −0.19, and ON-real−FROZEN −0.24. The effect is unrelated to wiring (ON-random is just as good), so it is a generic "any smooth bias helps in clustered instances" effect. Also R4 ISL4x−ACO +0.14 [+0.07,+0.21] excludes 0 in the harmful direction. Report them as "non-zero but under 0.5pp", not "no effect".

## Verified correct (no action)
- v2core.py:52 `isl=k%S`, `fly=k%F`. HET4 gives 5 ants per fly, ISL4 5 per island, and the pheromone update is per island using `m=isl==g` (line 65). The exchange adds the global best after the island's own deposit at (it+1)%ex (line 66) and is skipped when S=1. Island/tau indexing is right.
- Broadcast (lines 71-73): the reward is normalised over the ants of the chosen set (all ants, or the fly's ants), and the advantage subtracts the learner's own prediction `vu[f]`. With F=1, broadcast and private are identical (test 5b). Sign: shorter tour gives positive rt, and positive delta potentiates, as in v1 `train`. Per-signature mean followed by one update matches v1 (fly_heuristic.py:61-64). `update_u` matches `MB.update` (pot-q form; test 6). The 2-opt path (line 61) is applied before the length and best computations, so both depositing and learning see optimised tours, with no leakage to the RNG stream.
- Pairing: search seed 3i+rep is shared across arms and the learner does not consume the search RNG, so differences are paired (common random numbers).
- Bootstrap: over instances, on instance means across 3 reps (analysis_v2.py:13-14), which is correct. Power: the paired SD gives half-widths around ±0.10-0.14pp (95%) and ±0.16-0.2pp (99.4%) in R1-R3. A 0.3pp effect would be detected at 99.4%, and the ±0.5 margins are comfortable. R4 ±0.25 is well resolved (half-width ≈0.08). The bootstrap RNG is seeded globally across contrasts, which is fine.
- The headline family (8 contrasts, 99.4%): consistent with PREREG (H1 and H2 over 4 regimes). Three family members are not "★" on the other lists. Fine.

## Verdict
The statement "none of the four structural changes helps beyond ±0.5pp" is supported in the narrow sense: for this ACO (rho=0.9), these static features, these budgets, the tested arms equal tuned ACO within the CI, with enough power for a 0.3pp effect. Qualify it by saying generic small gains (≈0.2-0.3pp in clustered R3) appear that do not depend on wiring, and island splitting hurts (ISL4) unless exchange is added (ISL4x is still not better than ACO in R1/R2). "Real wiring adds nothing" is only weakly supported. The learner receives geometry-derived signatures that mostly replicate eta (corr 0.85), the learned valence has std ~0.08, and with alpha=0 the learner has no measurable effect over no learner. A fair statement is "no evidence that connectome wiring helps in this feature/budget setting, and the design could not have shown it", not "wiring is irrelevant". Fix first: item 1 (hash/analysis), then add NOTAU-none and a richer-feature or instance-specific edge-state variant before claiming anything about structure.
