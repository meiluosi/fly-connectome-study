# 预先登记：有界乘法规则消融（写于运行之前，2026-10-04）

问题：回路的低遗忘（相对 delta/EWC）来自**有界乘法学习规则本身**，还是仅仅因为它**学得更少**？

## 设定（冻结）
- 电路 MaleCNS 右半球（MR），行为读出（v4），随机气味任务和相似气味任务，T=48，PN 编码，每任务 5 气味、2 隔间，reps=3，q0=0.5。
- 新种子 2000–2029（30 个配对种子）；此前所有种子 0–99、1000–1059 不再使用。
- 条件：real（真实隔间）、none（不分隔间）。
- 规则变体（门控与教学符号逻辑不变，只改更新式；更新只作用于存在的边）：
  - bounded（现用）：压低 q ← q − η·x·q；增强 q ← q + η·x·(1−q)，q∈[0,1]。
  - additive0（无上界、下界 0）：压低 q ← max(0, q − η·x)；增强 q ← q + η·x。
  - multup（无上界乘法）：压低 q ← q − η·x·q；增强 q ← q + η·x·q，数值上限 q ≤ 1000。
- 学习强度扫描（η）：bounded {0.05,0.1,0.2,0.3,0.5,0.8}；additive0 {0.02,0.05,0.1,0.2,0.4,0.8}；multup {0.02,0.05,0.1,0.2,0.3}。
- 参照：delta 规则的学习率扫描 {0.02,0.05,0.1,0.25,0.5}。

## 核心比较：匹配学习量下的遗忘
- 每个种子、每个规则/条件得到一条（学习时准确率，遗忘）随 η 变化的曲线；在**预先设定的学习准确率目标 {0.70, 0.75, 0.80, 0.90}** 处线性插值，只比较双方曲线都覆盖的目标。
- 配对差（种子内）：遗忘(unbounded 规则) − 遗忘(bounded)，4000 次自助法 95% 区间。等价边界 ±0.02。
- **H1（"主要是学得更少"）**：两种无界规则在所有被覆盖的目标上，real 条件的差值区间都落在 ±0.02 内。
- **H2（"有界规则本身有保护作用"）**：两种无界规则在至少 2 个被覆盖的目标上，差值 ≥ +0.02 且区间下界 > 0。
- 两者都不满足 → 如实报告"混合/证据不足"。
- 次要（仅报告）：none − real 的遗忘差在匹配学习量下是否仍存在；delta 规则在匹配学习量下的遗忘。

## 不做的事
不改指标、目标点、边界；若某规则在所有 η 下都无法覆盖某目标，则该目标该规则标"不可比"，不外推。若出现 NaN/数值溢出，先记入 DEVIATIONS.md。
