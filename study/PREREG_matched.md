# 预先登记：匹配学习量下的遗忘比较（写于运行之前，2026-10-04）

动因：消融与审查表明，此前"分隔间比不分隔间遗忘少"几乎完全是学习量不同造成的，但支撑它的证据只有 MR 单电路、粗网格、仅均值。本登记把它补成带区间、覆盖两个电路与多种设定的检验。

## 设定（冻结）
- 电路：MaleCNS 右（MR，`core`）；FlyWire 右（FR，`core_fw2`，已恢复 MBON25,MBON34；该修复为事后，此处预先声明）。
- 任务：随机气味与相似气味（0.6 概率为变体），T∈{12,48}，v4 行为读出，PN 编码，每任务 5 气味、2 隔间、reps=3。
- **新种子 6000–6039（40 个）**；此前所有种子不再使用。
- 规则与条件：
  - bounded（现用规则）× {real, none}；
  - additive0（无上界、下界 0 的加法规则）× {real, none}。
- η 网格（更密）：bounded-real {0.03,0.05,0.08,0.12,0.2,0.3,0.5,0.8}；bounded-none {0.003,0.005,0.008,0.012,0.02,0.03,0.05}；additive0-real {0.02,0.05,0.1,0.2,0.4,0.8}；additive0-none {0.002,0.004,0.008,0.015,0.03}。

## 方法
- 每个种子、每个（规则，条件）得到（学习时准确率，遗忘）随 η 的曲线；在预先设定的目标 **{0.65, 0.70, 0.75, 0.80}** 处线性插值（只在曲线覆盖目标时）。
- 一个格子 = (电路, 任务, T, 目标)。**可比**：比较双方的曲线对至少 30/40 个种子覆盖该目标。否则标"不可比"，不外推。
- 配对差（种子内）+ 4000 次自助法 95% 区间。等价边界 ±0.02。

## 假设与判据
**H-M1（匹配学习量下，隔间化没有实质作用）**：对 bounded 规则，差 = 遗忘(none) − 遗忘(real)。
- 若 ≥75% 的可比格子区间完全落在 ±0.02 内 → 判"匹配学习量下无实质差异"。
- 若 ≥25% 的可比格子的区间整体落在 +0.02 之上（none 更差）→ 判"匹配学习量下仍有隔间化优势"。
- 其余 → "证据不足"。
**H-M2（有界规则没有保护作用）**：差 = 遗忘(additive0, real) − 遗忘(bounded, real)。每个电路内，若 ≥50% 的可比格子区间整体低于 0 且均值 ≤ −0.02 → 判"无界加法规则同学习量下遗忘更少"；若 ≥50% 的可比格子区间整体高于 +0.02 → 判"有界规则有保护作用"；其余 → "证据不足"。
- 另报告（无判据）：每个格子的 n 与均值，不可比格子的数量与原因。
