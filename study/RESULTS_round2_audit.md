## 2. 消融：有界乘法规则是不是低遗忘的原因？（`PREREG_ablation.md`）
在匹配的学习准确率下比较遗忘（MR，T=48，随机气味，real 条件，30 个新种子，种子内配对）：

| 学习准确率目标 | 无界加法 − 有界 | 无界乘法 − 有界 |
|---|---|---|
| 0.70 | **−0.039 [−0.049, −0.029]** | −0.030 [−0.049, −0.008] |
| 0.75 | **−0.047 [−0.060, −0.034]** | 不可比 |
| 0.80、0.90 | 不可比 | 不可比 |

相似气味任务同向（加法 −0.041 与 −0.050，乘法 −0.047 在 0.70）。
- **H1（差异在 ±0.02 内，"只是学得少"）：未满足**；**H2（无界规则遗忘更多）：未满足，方向相反**：在能比较的目标上，无界规则的遗忘**更少**。
- 解读：有界乘法规则**不是**低遗忘的来源，甚至在同样学习量下略差。覆盖范围有限：无界规则在 real 条件下学习准确率上限约 0.78（加法）与 0.71（乘法），0.80 以上不可比。
- **次要结果（来自对 none 追加更小 η 的扩展，见 DEVIATIONS.md；只有均值，没有算区间）**：匹配学习量下 none − real 的遗忘：随机任务有界规则 −0.002（0.75）与 +0.003（0.80），相似任务 −0.016 与 −0.013。**也就是说，"不分隔间遗忘多 0.15–0.25"几乎完全是学习量不同造成的**；匹配学习量后，两条曲线几乎重合（见 `../figures/fig4_ablation_matched_learning.png`）。

## 3. 第二轮 A：修正后的因果剂量反应（`PREREG_round2.md`）
入度分层划分、准确率遗忘（无 NaN）、新种子 4000–4029、不排除任何划分。

| 电路 | 重叠度范围 | **P-A1 偏回归系数（重叠度）** | P-A2 简单斜率 |
|---|---|---|---|
| MR | 0.10–0.57 | −0.005 [−0.020, +0.008] → **未通过** | +0.038 [+0.019, +0.053] → 通过 |
| FR（恢复 MBON25/34） | 0.05–0.45 | +0.007 [−0.006, +0.020] → **未通过** | −0.004 [−0.025, +0.017] → 未通过 |

结论：**预先登记的主检验在两个电路上都未通过。** MR 上存在简单相关，但一旦控制 KC 入度同质性与学习量，重叠度就没有可检测的独立作用；两者在 MR 里仍高度共线（r=−0.79），所以**这个数据区分不了二者**。"重叠度是遗忘的因果旋钮"这一说法应撤回，改为"在 MR 里与遗忘相关，但与入度同质性混杂，未能分离"。

## 4. 第二轮 B：修正后的基线（选择集 5000–5009，测试集 5010–5039；MR 与 FR）
- **EWC（精确对角 Fisher，λ 由选择集选出，8 个设定全选 λ=10）**：相对 delta 降低遗忘 +0.029 到 +0.120（全部区间下界 ≥ +0.019），P-B2 通过。
- **EWC 对回路**：最终准确率 0.82–0.93，回路 0.61–0.77，**8/8 设定 EWC 更高**；遗忘上 EWC 在 8 个设定里的 6 个更低（例外是 T=12 的相似气味任务，回路 0.065/0.081 对 EWC 0.099/0.112）。
- **真正的多头（读出使用任务标识）**：最终准确率 0.984–1.000，遗忘 ≤ 0.016。**注意**：它用任务标识读出，回路的行为读出是对全部 MBON 求和、不使用任务标识，二者不是同一设定，不能据此说"回路不如多头"。
- **P-B1 匹配学习量**：不可比。delta 的准确率对学习率几乎不敏感（lr 从 0.0005 到 0.002，学习准确率都是 0.966），无法靠调学习率匹配学习量。

## 5. FlyWire 与 MaleCNS 的分歧：能查到的来源
- **结构统计几乎一致**：真实重叠度相对打乱的 z 值，MR/ML/FR/FL = 8.0/8.7/7.6/7.5；KC 输入与隔间标签的聚类一致性（ARI）都很低（0.11–0.17），FlyWire 略低。分歧**不是**因为结构统计不同。
- **一个我造成的人为差异**：FlyWire 把 MBON25 与 MBON34 合并成类型 `MBON25,MBON34`，我的类型名转移找不到对应，每侧丢了 3 个 MBON，使 γ1、γ2 隔间的 MBON 数比 MaleCNS 少（3 对 5，7 对 11）。已修复（取 hemibrain 的 y1y2，较粗）。
- **事后检验（非预先登记，种子 3000–3059）**：修复后 FlyWire 的 real − shuffled 遗忘差：FR T=12 −0.014 [−0.031, +0.003]，T=48 +0.003 [−0.009, +0.014]；FL T=12 −0.010 [−0.025, +0.004]，T=48 −0.005 [−0.017, +0.008]。**没有出现与 MaleCNS 相同的正差异**，所以丢失的 MBON 解释不了分歧。男女数据的分歧仍然没有来源（可能是真实的个体差异，也可能是标签转移或噪声）。

## 6. 其他核实
- **KC 非嗅觉类型**（`verification/kc_nonolfactory.md`）：**支持，有细微差别**。KCg-d 主要接收直接视觉输入，KCab-p 主要接收经局部视觉中间神经元的间接视觉输入；少数 KCg-d 接收嗅觉输入。我的 128/2045≈6% 与文献的约 8% 视觉 KC 一致。Agent 通过搜索摘要而非全文读取，引用前应核对原文。
- **标签独立性**（`verification/label_independence.md`）：DAN→MBON **部分循环**（置信度中等，约 65%）：隔间标签最初来自光镜下的解剖位置，EM 中的身份确认可能部分用过突触连接；KC→MBON 在来源上独立，但同样锚定在同一套隔间几何上。我按建议做了稳健性检查：只取 MBON01–MBON21 类型（我假设的"典型 MBON"，59 个神经元）时，同隔间比例 0.929（打乱 0.095）；DAN 侧的过滤未起作用（所有带标签的 DAN 类型都落在我的正则内），所以只限制了 MBON。**91% 应被当作"与共享解剖几何一致"的检查，而不是独立证据。**

## 7. 现在能站住的结论
1. 隔间化门控的遗忘优势**主要是学习量混杂**：匹配学习量后，分隔间与不分隔间的遗忘几乎相同（单电路、粗网格、仅均值）。
2. 有界乘法规则**不是**低遗忘的来源（无界加法在同样学习量下遗忘更少）。
3. "重叠度因果影响遗忘"**未被确认**（控制入度同质性后消失）。
4. real 与 shuffled 隔间的差异：男性数据有一致的正差异，女性数据没有，**未确认**。
5. 这个回路不是更好的持续学习学习器：修正后的 EWC 在最终准确率上 8/8 更高，在 6/8 设定里遗忘也更低。
6. 隔间标签在 MaleCNS 里与 DAN→MBON 连接高度一致（91%–93%），但部分来自共享解剖，不是独立证据。
