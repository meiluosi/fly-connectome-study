# 蘑菇体隔间化与持续学习：模型与学习规则设计 (v2)

## 0. 要回答的问题

> 在真实的蘑菇体连线上做持续学习时，**隔间划分的真实结构**对遗忘有没有贡献？还是只要"分了隔间"就行，划分的具体内容无所谓？

这个问题把两件事分开：

- **有无隔间化**（门控是否按隔间限定）
- **隔间的真实内容**（哪些 MBON/DAN 归到同一隔间，以及每个隔间接收什么 KC 输入）

v1 的教训：只往下压的乘法抑制 + 手加的被动衰减，使"遗忘"几乎全是衰减的产物（衰减=0 时遗忘≈0）。v2 的核心修正是让规则**本身**能产生干扰，并把衰减变成单独的扫描变量。

## 1. 模型结构

| 部分 | 来源 | 状态 |
|---|---|---|
| KC→MBON 突触数 N_km | MaleCNS v1.0 真实连接（右半球：2045 KC，49 MBON，24091 条边） | **冻结** |
| MBON 与 DAN 的隔间归属 | MaleCNS 注释，经 `compartments.py` 映射到 16 个规范隔间 | 冻结 |
| KC 活动（气味编码） | v2：随机 5% 稀疏模式；v3：由真实 PN→KC 连线 + APL 的 k 赢家通吃生成 | 外生 |
| 突触效能 q_km ∈ [0,1] | 可学习，初值 0.5 | **学习** |

有效权重 `w_km = N_km · q_km`。真实突触数决定每条边的"容量"，q 决定当前强度。这样连接组的信息被完整保留，学习只在固定的容量范围内进行。

## 2. 学习规则（三因子，双向，有界）

对每个任务的每次气味呈现 x（KC 活动向量），隔间 c 的 DAN 给出符号 d_c：

- 压低（d = +1）：`q ← q − η_d · x_k · q`
- 增强（d = −1）：`q ← q + η_p · x_k · (1 − q)`
- 只作用于**被门控**的 MBON（所在隔间收到该任务的 DAN 信号），且只作用于真实存在的边（N_km > 0）。

为什么这样设计：

1. **双向**：真实蘑菇体里 DAN 既能引起压低也能引起增强（时序相关），使后一个任务能真正抹掉前一个任务。这是 v1 缺失的、产生干扰的必要条件。
2. **有界乘法形式**：q 不会越界，饱和自然产生容量限制。
3. **门控 = 隔间**：这是被检验的变量。

被动恢复 `q ← 0.5 + (q − 0.5)(1 − ρ)`，**主实验 ρ = 0**，ρ 只在敏感性分析里扫描 {0, 0.05, 0.15}。

## 3. 任务与指标

任务 j = (气味集 O_j，隔间集 C_j，标签 y_j ∈ {−1,+1})，教学符号 d = −y_j。

- 得分：`Score_j = y_j · (R_C(O_j) − R_C(新奇气味)) / R_C(新奇气味)`，R_C 为被门控 MBON 的平均响应。
- 记录**保留矩阵** R[i][j]：学完第 i 个任务后在任务 j 上的得分。
- `learned_j = R[j][j]`，`final_j = R[T−1][j]`，`forgetting_j = learned_j − final_j`。
- 必须同时报告 learned，不能只报 forgetting：学不会的臂遗忘自然也小（clfly 的 README 里也承认这个问题，"不遗忘"与"没学会"在多数臂上不可区分）。

## 4. 对照条件

| 条件 | 做法 | 回答什么 |
|---|---|---|
| real | 真实隔间 | 基线 |
| shuffled | 置换 MBON 的隔间标签（组大小不变） | 隔间**内容**有无贡献 |
| none | 每个任务门控所有 MBON | 隔间化**本身**有无贡献 |
| rewired | 每个 MBON 的突触前 KC 身份置换（入度、权重保持） | 真实 KC→MBON 连线有无贡献 |
| 算法基线（待做） | 同样 KC 特征上的 delta 规则 / EWC | 与常规持续学习方法的位置关系 |

任务–隔间分配策略也是一个变量：随机、均衡轮转、集中在少数隔间。

## 5. 预先登记的假设（先写下，再看结果）

- **H1**：none 的遗忘显著高于 real（隔间化本身有用）。
- **H2**：real 与 shuffled 的遗忘之差，配对 95% 区间**不包含 0**，且 real 更低。我对此**不乐观**：v1 里二者几乎相同，v2 初测也相同（0.070 vs 0.069）。如果区间包含 0，就如实报告"隔间的具体内容无贡献，只有隔间化有贡献"。
- **H3**：各隔间的遗忘可由其 KC 输入总量除以 MBON 数、以及接收的 KC 亚型来预测（容量异质性）。
- **证伪**：H2 在 v3（真实 PN→KC 编码）下仍为空，则"隔间内容无贡献"成立到本模型的精度。

## 6. 统计与验证要求

- 每个条件至少 100 个种子，**配对**设计（同一批气味、任务序列用于所有条件），报告配对差的置信区间。
- 单元测试：S1 单任务保留 = 学到的得分；S2 同气味同隔间相反标签在 none 条件下必须覆盖（已通过：任务 0 得分从 0.647 变为 −0.341）。
- 每次运行记录：种子、参数、数据文件哈希、代码版本。

## 7. 分阶段计划

- **v2（已跑通）**：随机气味，上述规则与对照。
- **v3**：用真实 PN→KC 连线和 APL 生成气味编码，让不同 KC 亚型有真实的稀疏度差异。
- **v4**：加入 MBON 神经递质符号，从各隔间读出整体"趋近–回避"行为，做真正的行为级任务。
- **v5**：与 EWC、delta 规则等算法基线同台比较；可选的外层元学习（搜索 η、门控策略），作为 RSI 的玩具类比，写作时明确不称为 RSI。

## 8. 已知局限（写作时必须保留）

- 只用 MaleCNS（雄性）。FlyWire 的隔间注释尚未核实。
- 气味编码在 v2 是随机的，没有 PN 输入的结构。
- 14 个 DAN（PPL106–108、PPL2 类）实例名无隔间标注，其中 11 个按目标 MBON 推断，3 个无法推断，未纳入。
- 隔间标签来自标注者，假设与 DAN→MBON 连接无循环依赖，**尚未核实**。
- 这是静态连线上的抽象学习规则，不是对真实生物物理的模拟，也不涉及 LIF 模型。
