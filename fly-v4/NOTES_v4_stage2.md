# 第四阶段 2：行为现象复现（登记：`PREREG_v4_stage2.md`，数字：`RESULTS_v4_stage2.md`）

这一阶段没有做独立审查。

## 结果
- **C1 梯度、C2 反馈抑制选择性、C3 反转：** 5 个学习器全部通过。稀疏编码加误差驱动规则就能产生这三种现象，与连线无关，所以它们不能区分真实连线。
- **C2：** 编码变稠（5% → 20%）后，相似气味的分离度相对下降（0.31 到 0.45）大于不相似气味（0.15 到 0.24），方向与 Lin 等 2014 的结果一致。
- **C4 消退：** real、shuffled、real_wshuf 通过（末值/峰值 0.18）；random（0.37）和 real_binary（0.31）不通过。
- **连线对比（99.4% 区间）：** real 与 shuffled、real_wshuf 在 spec、flip、ratio 上等价，aplsel 不确定。real 与 random 在 spec（+0.097）和 ratio（−0.185）上有明显差别，但 real_binary 也和 real 差别明显（spec +0.085，ratio −0.132）。

## 独立审查后的更正（`verification/review_stage2.md`）
- **“差别来自突触强度”没有得到支持。** 单位权重的学习器（random、real_binary）的 psi 是整数，平局很多，靠 1e-6 的抖动打破；同一气味两次产生的编码只重叠 0.61（random）和 0.66（real_binary），real、shuffled、real_wshuf 为 0.98 到 0.99。编码不稳定本身就足以解释峰值低（0.23、0.26 对 0.34）和反转、消退慢。real 与 random 还同时在入度和权重异质性上不同。能说的只有：打乱边的归属或重排权重（保持突触数分布）没有可测出的作用。
- **C4 的通过与否取决于固定学习率。** 重跑 30 个种子：real 的消退比值在学习率 0.05、0.08、0.11 下为 0.18、0.06、0.02；random 为 0.37、0.20、0.11，学习率 0.08 时 random 也通过。每个学习器内部，比值与峰值相关 −0.69 到 −0.96。real 与 random 的 ratio 差（−0.185）是同一个幅度效应，不是消退机制的差别。
- **C2 没有检验“不相似气味的分辨不受影响”。** 不相似气味的分离度在 95% 到 100% 的世界里也下降（约 15% 到 24%）；操作是把前 5% 改成前 20%，不是真的移除反馈抑制；稀疏和稠密两组的变体独立抽样，没有配对。只能写：相似气味的相对下降更大，方向与 Lin 等 2014 一致。随机稀疏的选择性反而最大。
- **C1、C3 接近平凡。** 任何误差驱动规则几分钟内就翻号（real、shuffled、real_wshuf 的翻号次数在 100 个世界里全是 5，区间退化为 [0, 0]）；C1 几乎由稀疏编码的重叠决定。它们只算正常性检查，不是对连线的检验。
- C4 只说明 delta 规则会降低响应，不是果蝇的消退：Felsenberg 2017 的描述是并行的相反记忆，单痕迹模型只能擦除。C3 的来源没有对应到具体论文。
- 判定规则：阶段 2 的 `tier()` 在“meaningful”上只看均值 ≥ s，登记没有定义；改用严格规则不改变任何标签。99.4% 是 8 个对比的 Bonferroni 取整，略偏宽松（99.375%）。真实连线只有一个实例，real 与其他学习器的区间很窄是因为只含气味抽样的方差。

## 现在能说什么
5 个学习器都复现了梯度、相似气味的选择性下降和反转，这些是稀疏编码加误差驱动规则的一般性质；没有测出拓扑相关的差别（real ≈ shuffled ≈ real_wshuf）。real 与单位权重学习器之间的差别混杂了编码稳定性、入度和权重异质性，不能归因到某一项。
