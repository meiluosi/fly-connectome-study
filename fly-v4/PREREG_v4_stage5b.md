# 预先登记：第四阶段 5b（嗅小球通道的定向病变：更忠实的 hub / bridger 移植）

写于运行测试之前。冻结文件与哈希：`PREREG_v4_stage5b.sha256`。无调参（学习率 0.05）。

## 为什么有 5b
阶段 5 把“hub / bridger”换成了 KC 的输出强度和激活频率，结果是没有结构性瓶颈。用户问这是不是借鉴方式的问题。检查：WorldSimulationLab 里 hub 之所以重要，是因为互动高度集中（前 2% 用户占 32% 的事件）；蘑菇体的 KC 层远没有这种集中：KC 输出强度前 2% 只占 4%（基尼系数 0.24），KC 的嗅小球入度均值 5.3（标准差 2.4），KC 间共享嗅小球的度前 2% 占 4%。集中度稍高的是嗅小球层面：嗅小球的 KC 扇出基尼系数 0.38，前 10% 的嗅小球占 22%。所以更忠实的移植应在**嗅小球（PN 通道）层面**做，并用拓扑上的“桥接性”而不是频率。

## 定义（与结果无关，在数据上固定）
- hub 通道 = KC 扇出（有突触的 KC 数）最高的嗅小球。
- bridger 通道 = 在扇出不低于中位数的嗅小球里，按参与系数 PC = 1 − Σ_g (k_g/k)²（g 取 KC 的三个叶群：γ、αβ、α′β′）从高到低；PC 高 = 把输入分散给不同叶群的通道，即跨“模块”的连接。
- 排序用被评估的那套连线自己算（打乱连线和随机稀疏连线各算各的）。
- 病变 = 沉默 m 个通道（所有气味该通道的响应置 0），m ∈ {3, 7, 13}；对照 = 随机抽同样数量的通道。post = 训练后测试时沉默（突触保持）；pre = 训练和测试都没有这些通道。

## 设计
任务 door_class（真实气味 + 随机类别标签，**干净**）与 door_teacher_real（标签来自真实连线教师，**循环**：教师用 P0，沉默教师依赖的通道会破坏标签信号本身，该任务只作参照，不用来下“瓶颈”结论）。学习器 real、shuffled、random 连线 + 有界乘法 delta 规则，学习率 0.05，400 次试验；测试种子 5000–5099；预试（种子 1000–1005）看到 door_teacher_real 上 real 连线 hub 通道的 pre 与 post 病变都有明显超额损失，door_class 上没有。

## 主结论族（7 个，99.3% 区间，超额损失，三档 s = 0.03）
1. door_class、real：post，hub 13；2. 同，post，bridger 13；3. 同，pre，hub 13；
4. door_teacher_real、real：pre，hub 13（循环任务）；5. 同，pre，bridger 13；
6. door_teacher_real：post，hub 13，real − shuffled；7. door_class：post，hub 13，real − shuffled。
其余（所有剂量、hub/bridger、pre/post、连线）为描述性，95% 区间。

## 解读规则与预测（预测不是判据）
- 干净任务 door_class 上，超额损失等价 = 没有测出嗅小球层面的结构性瓶颈；meaningful 才能说有（需 pre 也成立才算结构性，因为 post 可以由读出的依赖解释）。
- door_teacher_real 的结果只说明“教师信号依赖这些通道”，不下瓶颈结论。
- 预测：door_class 上等价；door_teacher_real 上 real 连线的 hub 通道有 meaningful 的超额损失。

## 已知局限（接受）
只有两个任务；通道级病变不等于生物病变；参与系数只用 KC 叶群当模块，没有用气味类别或功能模块；hub 与 bridger 在小剂量下有重叠；不做强化（只有消融）。
