# Review of fly-v4 stage 2 (context-free)

Hashes: all 5 files in PREREG_v4_stage2.sha256 verify OK (the one "improperly formatted" warning is the comment header line). The analysis reproduces RESULTS_v4_stage2.md exactly (diffed against a copy run in scratch). Result files were written after the freeze (01:49:53 freeze, 01:49:54+ results).

## Ranked findings

1. CONFIRMED (conclusion about mechanism): the "synaptic strength, not topology" explanation in NOTES is confounded by KC-code tie instability. In `codes_for`, the top-5% selection uses jitter 1e-6 only as tie-breaker. With unit weights (random, real_binary) psi is integer-valued, so many ties; the code evoked by the SAME odour is re-drawn at random on each presentation. Measured self-overlap of two codes for one odour (k=102 of 2045): real 0.988, shuffled 0.983, real_wshuf 0.979, real_binary 0.657, random 0.609. So the random/binary arms train and test on unstable codes, which by itself lowers the peak (0.23/0.26 vs 0.34) and slows reversal/extinction. This is a discretisation artifact, not evidence about "input strength (synapse count)" as a biological variable. NOTES' sentence that real_binary differing means strength matters is therefore not established; the data only show that arms with tie-heavy codes behave differently. Also, real_wshuf = real and shuffled = real show only that edge-to-weight assignment and glomerular identity are irrelevant, not which property of the weight distribution matters. random also differs in in-degree (always 6) and has no heterogeneity, so it is confounded on several axes. "Topology has no measured effect" is fair; "difference comes from strength" is not demonstrated (PLAUSIBLE alternative: ties/code reliability, CONFIRMED to exist).
2. CONFIRMED: C4 pass/fail is an arbitrary function of the fixed ETA. I re-ran world() for 30 seeds at other ETAs: real ratio 0.181 (eta .05), 0.063 (.08), 0.023 (.11); random 0.371 (.05), 0.200 (.08, peak 0.325 ~ real's peak at .05, would PASS 0.25), 0.110 (.11). Within each arm the per-world ratio correlates with peak (r = -0.69 to -0.96). So NOTES' explanation of the C4 failures (small response amplitude -> slower learning) is supported, but only by this extra run, not by RESULTS; the mechanism is that the bounded rule has g = eta*|delta|, so extinction speed scales with the current response (decay is slower when v is small). Consequence: the "5 arms pass/fail C4" table mostly measures amplitude at one ETA, and the real-vs-random "ratio meaningful" tier (-0.185) is the same effect. Not a topology/biology finding. NOTES hedges ("不一定合适") but also states the strength story as fact (see 1).
3. CONFIRMED: C2 does not test "no impairment of dissimilar discrimination". Criterion = (rel. drop sim) - (rel. drop dis) >= 0.10. The dissimilar separation drops in 100% of worlds for real/shuffled/real_wshuf (95% for binary): sep_dis 0.323 -> 0.273 (real; 15%), 0.22-0.24 for others. The PREREG states the literature claim as "does not impair dissimilar"; the criterion passes with a 15-24% impairment, and NOTES reports only the difference. Additionally the manipulation is raising top-k from 5% to 20% (a fixed-k change, which also changes overlap with any A/B), not removing APL feedback; sparse and dense arms use independently drawn variants/jitter (unpaired). Direction "consistent with Lin 2014" is fine; "reproduces" is generous.
4. CONFIRMED: C3 (reversal) is trivially satisfied by any error-driven rule: after 10 trials at +1 (v about 0.34), target -1 must cross zero in a few trials. flip is exactly 5 in all 100 real/shuffled/wshuf worlds (zero variance), so the "equivalent" tiers for flip have degenerate CIs [0,0]. It cannot discriminate arms, and the "APL inhibits initial memory" rationale in the PREREG is not what is tested. C1 is nearly guaranteed by code overlap in a sparse code (10 repeats of the o=6 odour differ only by jitter). Both are positive controls at best; NOTES does say they do not discriminate arms, which is correct.
5. CONFIRMED (minor, ratio): ratio = vs[-1]/v0 where vs[-1] is the value before the 30th update and v0 is a fresh evaluation; `nanmean` silently drops worlds with v0<=1e-6 (none occurred: 0 NaN in all arms), so no practical effect now. reldrop is computed on pooled means (ratio of means) inside the bootstrap, which is acceptable and consistent with the PREREG text ("用世界均值"); with small sep_sim_s it would be unstable but here values are 0.06-0.11 and CIs are tight.
6. CONFIRMED (deviation, undisclosed): tier() here is "meaningful if CI excludes 0 and |point| >= s" (point estimate only). analysis_v4b.py's earlier tier distinguishes meaningful-strict (min(|lo|,|hi|) >= s) vs marginal. The PREREG only says "三档" without defining it. No label changes in this stage (re-checked: spec real-random lo .094 > .05; ratio -0.193 < -0.10; real-binary ratio -0.147 > .10), but the rule is looser than previous stages and not written in the PREREG. Also C1/C2 per-arm passes use unadjusted 95% intervals, while only the 8 contrasts use 99.4% (0.05/8 = 0.00625 -> 99.375%, so 99.4% with 0.3% tails is correct, slightly liberal by rounding).
7. CONFIRMED (inference scope): bootstrap resamples worlds, but real/real_binary/real_wshuf-with-fixed-P share ONE wiring instance (real P is constant), so the within-real variance is only odour sampling (peak range 0.331-0.34). The very narrow real-vs-random/shuffled CIs say nothing about wiring-to-wiring variability for the real arm; "equivalent" tiers reflect near-deterministic outputs. Worlds are not paired across arms (seed is shared but make_P consumes rng differently, so A differs), so pairing by index gives no variance reduction but is not invalid.
8. CONFIRMED (PREREG vs code): variant(), KFRAC switching, train() update path are correct. variant keeps exactly o glomeruli of A and fills from outside A (o=0 yields zero overlap); V.KFRAC is a module global read at call time and restored in finally; train uses the same jittered code for prediction and update (the `b0,sc=` line in train is dead code). C1-C4 thresholds and counts (10 variants, 5 pairs, 10/30 trials) match the PREREG. Pilot-based change of ETA/trials and replacing accuracy with separation is disclosed in the PREREG as pre-freeze.
9. PLAUSIBLE (literature): sources are labelled "搜索摘要级" in the PREREG, which is honest, but the C3 source ("Waddell 组反转学习研究, APL 抑制初始记忆") has no named paper, and Felsenberg 2017 describes extinction as a parallel opposing (dopamine-driven) memory, which the single-trace model explicitly cannot implement; the model's extinction is erasure, so C4 "reproduces extinction" mostly says the delta rule reduces response. NOTES's "方向与 Lin 等 2014 一致" is reasonable but should not omit the dissimilar-discrimination impairment (finding 3). I could not check the citations (no full texts), so the strength cannot be fully verified.

## NOTES vs RESULTS
- "C1, C2, C3 all 5 pass; C4 real/shuffled/wshuf pass, random 0.37 and binary 0.31 fail": matches RESULTS.
- "real ~ shuffled ~ wshuf equivalent on spec, flip, ratio; aplsel uncertain": matches (aplsel -0.049 [-0.110,+0.008]).
- "Differences come from KC input strength": not supported beyond what findings 1-2 allow; the stage-2 data cannot separate strength from code-tie noise or amplitude-at-fixed-ETA.
- Missing from NOTES: aplsel real-random is "small-real" in favour of random (random has the larger selectivity), and the dissimilar-impairment caveat.
