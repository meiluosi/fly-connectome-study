# Review of fly-v4 stage 0 (context-free)

Frozen hashes all verify (PREREG, v4core, run_v4, real_odours, tuning_v4.json, analysis_v4). 5400 result files = 6 tasks x 9 learners x 100 seeds.

## Findings, ranked

1. CONFIRMED - Positive-control gate is circular (matched-feature oracle). teacher_real labels are the sign of a linear readout of the codes_for(U, P0) code; the "real" student uses the identical P0 and identical KC->MBON architecture. It wins because it has the teacher's features, not because real wiring helps learning in general. Gate therefore shows only "pipeline can detect a feature-matched student", and the 7-family headline #5 (door_teacher_real real-random, +0.033) is the same tautology, not evidence of natural-task benefit. The negative control is not symmetric: no student with the teacher_random wiring (oracle) is run, so there is no test that an equally matched random wiring wins. linear_teacher gate is likewise matched by construction. Note the match is not exact: tie-breaking jitter gives only ~63% identical KC codes between teacher and student on binary odours, so the real student's advantage is partly capped. Gate is still fair in the narrow sense (eta tuned per learner, same budget).
2. CONFIRMED - "silenced" metric is biased and meaningless for linear. MBL.val(silence=...) zeroes silenced KC weights but leaves b0/sc computed from the unsilenced code, so silenced KCs act as maximally depressed rather than absent (systematic bias toward one sign, not graceful degradation). For linear learner `sil=curve[-1]`, i.e. silenced == final (verified: 0.879 == 0.879 in linear_teacher table). Any silencing robustness claim (esp. vs linear) is invalid.
3. CONFIRMED - "acc50" is actually accuracy after 40 trials (curve[int(50/20)] = curve[2], t=40). Mislabelled; PREREG says 50 trials.
4. CONFIRMED - Tier rule is lenient: "meaningful" uses the mean >= 0.03 only, not the CI. door_teacher_real real-random = +0.033 [+0.027,+0.039] is labelled meaningful although the lower bound is below s. It is the only door headline test that is "meaningful", and it sits on the threshold (and is the circular one, see 1). Conclusions should say "small-to-meaningful". (Follows PREREG text, so not a deviation, but a weak rule.)
5. CONFIRMED - Headline-family handling is fine: 99.3% ~ 1-0.05/7 Bonferroni; stars match the 7 listed contrasts, ADs inherit base eta as registered. Minor: 4000 bootstrap draws give ~14 points per tail at 99.3% (noisy endpoints); shared global rng(71) makes CIs depend on call order (gate recomputes CIs with different draws than the table, so printed numbers can differ slightly). Non-headline contrasts (95%) are not multiplicity-corrected and many are tiered; they are labelled descriptive, OK.
6. CONFIRMED (minor) - Test-odour counts differ: door test sets are 91 held-out odours, not 300; DoOR covers 46 glomeruli in odours.npz (PREREG says 47); adaptation divides by max(u.sum(),1) so an all-zero DoOR vector would shrink a column (conservation not exact). Neither changes conclusions.
7. CONFIRMED (not a leak) - Tuning/test leakage: world seeds 1000-1019 vs 5000-5099, run rngs 2000-2019 vs 6000-6099, teacher_random aux seed+9: no overlap (verified). Only shared resource is the fixed DoOR odour set and fixed P0 teacher, which is inherent to the design; eta selection from 4 values has negligible leakage. Concern that MB etas sit on the lower grid edge (0.05) was checked: eta 0.01/0.02 are worse on tuning seeds for real/random/shuffled (teacher_real real 0.730/0.740/0.753), so the grid is adequate. Tuning gaps between top two etas are often <0.005, so eta choices are noisy but harmless.
8. PLAUSIBLE - Confound in real vs random: real P0 has heterogeneous in-degree and weights, random has 6 unit inputs per KC. "real_wshuf"/"shuffled" partly control this (shuffled keeps column weights). Door results (real ~ shuffled ~ random) are consistent with no topology effect, but real-vs-random differences cannot be attributed to topology without the shuffled contrast; headline #4/#5 use random only.
9. PLAUSIBLE - "+ad" is not a fair "wiring as initialisation" test: 300 Hebbian steps at 0.05 retain ~46% of original column per KC after ~15 activations, and it drops door_teacher_real accuracy for all wirings (-0.03 to -0.064), so the adaptation rule itself hurts; null in +ad contrasts (#6,#7) mostly says "this rule washes out wiring", as the PREREG limitation partly admits.

## RESULTS_v4_stage0.md
It contains only auto-generated tables and gate output, no interpretive prose, so no unsupported conclusion text. Gate "passes" statement is accurate under the registered rule but should be read per finding 1. PREREG predictions: door real~random was falsified for door_teacher_real (real better by 0.033) and the door_teacher_real "+ad real-random" is equivalent; linear "not worse than MB" holds except door_teacher_real where real beats linear by 0.032. Family task is saturated (~0.97-1.0), uninformative as noted. Any claim from silenced/acc50 columns should be withdrawn or relabelled.

## Deviations from PREREG
- acc50 is at 40 trials (finding 3).
- Door test set 91 odours; 46 not 47 glomeruli covered (finding 6).
- No other deviations found: seeds, grids, KFRAC, n_pre/eta_p, 7-test family, 99.3% level, s=0.03, tier rule all match. Hash file confirms frozen code equals run code.
