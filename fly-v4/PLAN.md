# 第四阶段计划：给“连线是否有用”一个能测得出来的检验

状态：计划，尚未登记，尚未运行。每个阶段先写预先登记（`skills` 的 `preregistered-experiment`），过了前一阶段的门槛才进入下一阶段。

## 为什么要做
前三个阶段的主要局限：从没有阳性对照；气味是合成的（随机抽几个小球），对随机连线天然公平；特征与已有启发式重复；没有行为层面的有效性门槛；只比平均值。

## 评估规则（所有阶段共用，登记时固定）
三档：meaningful（区间排除 0 且 |效应| ≥ s）、small-real（区间排除 0 且 |效应| < s）、equivalent（区间在 ±s 内且含 0）、否则 uncertain。s 在登记时按“占基线的比例”或成本收益写明。主结论族用多重校正，其余只描述。结果同时报告方差、小样本表现、鲁棒性。

## 阶段 0：不需要下载，先证明设计测得出来
**0a 阳性对照（门槛）**
- 构造一个“连线匹配”的任务：气味取自**真实 KC 的输入组合**（随机抽真实 KC，把它的输入小球集合作为一个气味），奖励与气味身份绑定。预期：真实连线（有一个 KC 恰好对应这个组合）明显优于打乱和随机稀疏。
- 构造一个“枢纽小球”任务：气味按各小球的 KC 扇出加权抽取，奖励与是否含枢纽小球相关。
- 构造一个“合取”任务：奖励取决于两个小球同时出现，线性学习器学不会，稀疏扩展应学得会（检验“稀疏扩展”这条）。
- **门槛：** 在这些任务里，现有的比较流程能检出预期效应（“连线匹配”任务里真实 − 打乱达到 meaningful；合取任务里蘑菇体 − 线性达到 meaningful）。过不了，就先修设计，不进入后面。
**0b 混合体对照**
- 补全拓扑与权重的拆分：`real_weights_shuffled`（拓扑真、权重在真实边之间打乱）和现有的 `shuffled`（拓扑乱、每个 KC 的权重多重集合不变）、`real_binary`（拓扑真、权重全 1）。
**0c 把连线当初始化，测样本效率**
- 从真实 / 打乱 / 随机稀疏连线出发，允许 PN→KC 突触以一条局部、奖励调制的规则缓慢学习；比较达到固定表现阈值所需的奖励次数或步数（累计奖励曲线下面积 + 达标时间）。
**0d 新指标**
- 世界间方差、前 N 次奖励内的表现（小样本）、对气味噪声（小球随机丢失）、KC 随机沉默、MBON 损毁的鲁棒性。

## 阶段 1：真实气味（需要下载，等批准）
- 数据：DoOR 2.0 的气味—受体响应矩阵和受体—小球映射。
- 把每个气味变成 65 维小球响应向量（缺数据的小球用基线）；相似的气味用响应相关性定义；用化学类别给奖励（酯类吸引、酸类厌恶等，作为明确标注的假设，不是实验事实）。
- 检验：真实连线的“扇出不均”是否对应自然气味的统计，从而在真实气味任务里出现优势。
