# 预先登记：第四阶段 0（阳性对照、真实气味、连线作初始化、新指标）

写于运行测试之前。冻结文件与哈希：`PREREG_v4_stage0.sha256`（含调参结果，调参先于冻结）。评估规则：三档判定（见 `../analysis-tiers/NOTES.md`）。

## 问题
1. **阳性对照（门槛）：** 当连线确实有作用时，这套比较流程能不能检出？（教师—学生任务：标签由真实连线的蘑菇体教师生成。）
2. **真实气味：** 在 DoOR 2.0 的真实气味—小球响应向量上，真实连线是否优于打乱 / 随机稀疏 / 线性学习器？
3. **连线作初始化：** 允许 PN→KC 做无监督 Hebbian 适应后，真实连线的起点是否仍有优势？
4. **新指标：** 样本效率（学习曲线下面积）、小样本（50 次试验后）、最终准确率、对输入噪声和 KC 沉默的鲁棒性、世界间方差。

## 任务（一个“世界”= 一个任务实例；种子决定气味池、标签和连线抽样）
| 任务 | 输入 | 标签 | 角色 |
|---|---|---|---|
| teacher_real | 随机 6/65 小球气味 | 真实连线蘑菇体教师（随机 KC→MBON 突触）的符号，按中位数平衡 | **阳性对照**：预期真实学生 > 打乱、随机 |
| teacher_random | 同上 | 随机稀疏连线教师 | **阴性对照**：预期真实学生不优于随机 |
| linear_teacher | 同上 | 随机线性规则的符号 | **对照**：预期线性学习器 > 蘑菇体学生 |
| family | 两个气味家族的变体（共享 4/6 小球），旧任务 | 家族 | 旧设定（预期饱和，作连续性参照） |
| door_class | DoOR 气味向量（301 种气味，≥3 个测得的小球） | 每个世界随机给每个化学类别一个 ±1 | 真实气味、类内泛化（不含生物学价值假设） |
| door_teacher_real | 同上 | 真实连线教师的符号 | 真实气味 + 连线相关的标签 |

每个世界：训练流 600 个气味（door 任务从训练气味有放回抽样，70%/30% 划分训练/测试气味），测试集 300 个（door：全部留出的气味）。试验 400 次；每 20 次评估一次留出准确率。

## 学习器
MB 学生：PN→KC 连线 ∈ {real, shuffled, random, real_binary, real_wshuf（拓扑真、突触数在真实边之间打乱）}；KC 取前 5%；KC→MBON 为有界 delta 规则。线性学生：65 维上的 Rescorla–Wagner。“+ad”：训练前用 300 个训练气味做无监督 Hebbian 适应（活跃 KC 的输入向当前气味移动，学习率 0.05，每个 KC 总突触权重守恒），仅用于 real、shuffled、random。
学习率 eta 在调参世界（种子 1000–1019，20 个）上按每个（任务，学习器）从 MB {0.05, 0.15, 0.4, 1.0}、线性 {0.1, 0.3, 1.0, 3.0} 中选 auc 最高者；“+ad”继承基础学习器的 eta。适应的参数（300、0.05）固定，不调参。

## 评估
测试世界种子 5000–5099（100 个/任务）。配对差（同一世界、同一抽样），对世界做 4000 次自助法，95% 区间；**主结论族（7 个，99.3% 区间）：**
1. teacher_real：real − shuffled（auc）；2. teacher_real：real − random（auc）；3. linear_teacher：linear − real（auc）；
4. door_class：real − random（auc）；5. door_teacher_real：real − random（auc）；
6. door_class：real+ad − random+ad（auc）；7. door_teacher_real：real+ad − random+ad（auc）。
其余（acc50、final、noisy、silenced、其他学习器对）为描述性，95% 区间。
**三档：** 最小有意义效应 s = 0.03（准确率点）。meaningful（区间排除 0 且 |均值| ≥ s）、small-real（排除 0 且 < s）、equivalent（含 0 且在 ±s 内）、uncertain。

## 门槛与预测（预测不是判据）
- **门槛：** teacher_real 的对比 1、2 都达到“real 更好 meaningful”，并且 linear_teacher 的对比 3 达到“linear 更好 meaningful”，才认为设计能检出连线/结构的作用；teacher_random 的 real − random 不应是“real 更好 meaningful”。**门槛不过：**结论写“设计未通过阳性对照”，不解读 door 任务。
- 预测：门槛通过；door 任务上真实 ≈ 随机（等价或 small-real）；“+ad”缩小各连线之间的差距；线性学习器在多数任务上不差于 MB。

## 已知局限（接受）
教师—学生任务衡量的是“和教师连线一致带来的优势”，不是自然适应性；door 的化学类别标签是随机分配，不含生物学价值；DoOR 只覆盖 65 个小球中的 47 个（缺数据的小球为 0）；适应规则是我选的一种，不是真实的可塑性；调参只在 4 个学习率上做。
