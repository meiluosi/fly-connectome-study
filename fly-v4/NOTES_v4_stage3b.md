# 第四阶段 3b：个体差异，加入第三只果蝇（登记：`PREREG_v4_stage3b.md`，数字：`RESULTS_v4_stage3b.md`）

这一阶段没有做独立审查。数据：hemibrain v1.2 的 PN→KC（经用户同意下载，46 MB，来源与校验和见登记）。三只果蝇（MaleCNS 雄、FlyWire 雌、hemibrain 雌）五个半球；所有学习器取 1801 个 KC（hemibrain 有输入的 KC 只有 1801 个），数值与阶段 3 不可直接比。

## 结果（auc，学习率 0.05，99.4% 区间）
| 教师 | 学生 | 对 random | 对 marg（保留度数与权重、按嗅小球总量抽样） |
|---|---|---|---|
| H_R | M_R | +0.022（small-real） | +0.002（等价） |
| H_R | F_R | +0.024（small-real） | +0.000（等价） |
| M_R | H_R | +0.026（small-real） | +0.006（small-real） |
| F_R | H_R | +0.012（small-real） | −0.004（small-real） |

door_class（真实气味 + 随机类别标签）：H_R − M_R = −0.009（small-real）；四个真实半球、marg 和 random 彼此都在 0.01 以内。

## 怎么读
- **与阶段 3 一致：** 另一只果蝇的真实连线做学生，比随机稀疏连线好（+0.012 到 +0.026），但每一个都低于 0.03（small-real）；与只保留嗅小球层面输入总量的对照几乎相当（−0.004 到 +0.006）。所以第三只果蝇没有改变阶段 3 的结论：跨个体共享的可用结构基本等于嗅小球层面的输入总量，幅度小。
- 这次的跨个体优势比阶段 3 更小（阶段 3 里雄 → 雌 +0.036）。可能的原因：K 从 2018 降到 1801；换了教师/学生组合；噪声。没有检验是哪一个。
- 自指的上限（教师 H_R 配学生 H_R）0.680，其他个体 0.650 到 0.652，比 random 的 0.628 高 0.02；也就是说，即使是同一个体的连线，优势也很小（+0.05）。
- door_class 上，个体差异和连线真假在这个任务上没有测出影响。
- 局限同阶段 3：三只果蝇，两种性别；突触检测方法不同；教师—学生任务衡量的是与教师连线的一致程度；FlyWire 的权重比其他两套小。
