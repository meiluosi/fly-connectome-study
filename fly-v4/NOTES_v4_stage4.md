# 第四阶段 4：效价专门化隔间 + 多巴胺时序规则（登记：`PREREG_v4_stage4.md`，数字：`RESULTS_v4_stage4.md`，审查：`verification/review_stage4.md`）

## 结果
- **A 时序现象：** comp_real、comp_shuf、comp_shufbal 都通过 P1–P3：奖励前向配对得到正价值，后向配对得到负价值（惩罚相反）；|ISI| = 8 时效应降到约 3%；消融 PAM 簇只废掉奖励学习，消融 PPL1 簇只废掉惩罚学习。关掉后向增强（notiming）后，后向配对的效应归零。这些由规则本身决定，与簇的具体分配无关，是自洽检查，不是对真实结构的检验。
- **B 样本效率：** comp_real 与原有规则（global）相当或略差：door_class −0.006（等价）、linear_teacher −0.018（small-real）、teacher_real −0.065、door_teacher_real −0.027。comp_real 明显好于簇标签重排的对照（+0.02 到 +0.12）。
- **C 持续学习（4 个任务，随机 ±1 标签）：** comp_real 最终准确率比 global 高 +0.044，比匹配学习量的 global 高 +0.048，比 comp_shufbal 高 +0.119。前两个的 99.3% 区间下界是 +0.024 和 +0.029，低于 0.03，按登记的三档只算 small-real 到 meaningful 之间（分析脚本里标为“边缘”）。

## 审查后的读法
- **“隔间化减少遗忘”没有得到支持，不能这样写。** 能写的是：带簇门控的“只抑制”规则在真实的 PAM/PPL1 划分下，比双向的全局规则多保留约 0.03 到 0.05 的准确率，幅度边缘。前沿表上，在刚学完准确率相同的几个点上，优势是 +0.028、+0.048、+0.041、+0.004，headline 的 +0.048 是最有利的匹配。
- **“真实划分比重排好”大半是学习水平的差别。** 审查用 comp_real 的学习率重排了 200 次（质量平衡），真实 0.849，重排均值 0.709，约 7.5% 的重排不低于真实；在“刚学完”接近真实的重排里，最终准确率均值 0.837，对真实 0.849，没有优势。重排的对照本身噪声大（±10% 质量平衡仍留下 r = +0.50 的残差）。所以 comp_real − comp_shufbal 的区间不能说明真实划分特殊，只能说真实划分属于能学会的那一类（比约 92% 的重排好）。
- **差别来自规则族，不是读出符号或隔间角色。** 双向的全局规则对读出符号翻转不变（审查用角色符号重建的 global 与原 global 前沿一致）。COMP 的不同是：只抑制、按簇和误差符号门控，突触不能被增强，所以旧痕迹不会被覆盖。缺一个“只抑制、不分簇”的对照：我的 unsigned 学习器（所有 MBON 对任何误差都抑制）在所有任务上学不会，说明分簇是只抑制规则能工作的前提，二者混在一起，无法拆开。
- **划分依赖具体分配：** 按递质符号划分（审查试过）只有随机水平（0.52 到 0.54），真实的 PAM/PPL1 划分能学会。
- **comp_real 在任务间更平：** 第一个任务保留 0.833（global 0.716），最后一个任务 0.859（global 0.928），部分是首因/近因的权衡，不是处处遗忘更少；comp_real 对学习率也更不敏感（0.05 到 1.0 持平，global 在大学习率下变差）。
- 归一化遗忘对弱学习器不稳（comp_shuf 的均值 2.15，中位数 0.27）。
- 未做：觅食环境里的重做；DAN→MBON 的连线细节（簇划分用的是文献通行假设，没有用 MaleCNS 的 DAN 突触数据）。

## 能说什么
真实 PAM/PPL1 划分加只抑制、多巴胺预测误差门控的规则，是一个能学会的学习器，复现了多巴胺时序造成的记忆符号翻转；在持续学习的随机标签测试里有边缘的保留优势，但优势不能归因到“隔间化”本身，也不能归因到真实划分比其他能学会的划分更好。样本效率任务上它不优于原规则。
