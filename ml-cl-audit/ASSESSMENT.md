# 这个审计项目的价值评估（2026-10-10）

写这份评估的人（我）参与了项目的大部分，有偏向。

## 比上一个项目更有价值的地方
1. **问题更尖锐、结果无论正负都有信息量**：FlyModel 是否优于简单的免回放基线，答案是"否"，而且是在预先登记、独立验证集调参、独立审查之后得到的。
2. **有一个具体、可检验的发现**：论文式的"稠密编码失败"对照把"表示"和"分类规则"混在一起，拆开后稀疏表示的价值缩小到 MNIST-20 上约 1/17、CIFAR-100 弱特征上约 1/7、强特征上符号反转。这个发现不依赖玩具模型。
3. **对 ML 工程岗位的信号更直接**：特征提取、类增量基准、基线实现与健全性测试、验证集调参协议、预先登记、独立审查、并发缓存缺陷的发现与修复。
4. **范围可控**：一篇论文、三个基准、CPU/MPS 可跑。

## 仍然成立的限制（批判性）
1. **新颖性有限，且我没有系统核实**：评测纪律（匹配可塑性、公平调参）已有文献；我的检索只确认"没找到系统复核果蝇类方法的工作"，置信度约 70%，检索有局限。"被 SLDA 超过"也不令人意外：SLDA 是已知的强免回放基线。
2. **只审计了一篇论文**，CIFAR-100 的数字没有数值复现（论文特征处理没写清），所以 CIFAR 只能作相对比较。
3. **H3 不完整**：CIFAR-100 的反向传播基线因预算未完成；MNIST 的 H3 里 EWC/微调是崩溃的基线，ER-200 的最优学习率在网格边缘。所以"FlyModel 优于 EWC/小回放"这半条结论证据最弱。
4. **探索性对照是看到结果后加的**，需要独立复核才算稳。
5. **作者的实现与论文未必一致**：FlyModel 无官方代码，我按论文文字实现，MNIST-20 复现在容差内但略低于论文。
6. 与你最初的 RSI/AGI 动机依然没有直接联系。

## 综合判断
- **科学贡献：小到中。** 一个干净、经过审查的、范围明确的复核，价值在于方法与可信度，不在于新原理。
- **作品集价值：中到好，高于上一个项目。** 它能被一句话讲清：我复核了一个"仿生"持续学习方法，发现它被更标准的免回放基线超过，并发现其关键对照夸大了结论，过程中也更正了自己的错误。
- **最该继续的方向**（若要继续）：把 H3 补完整（至少 CIFAR-100-B 的交错流）；对第二篇方法（Fly-CL 或 FlyPrompt）做同样的审计，检验"被标准免回放基线超过"是否是这一类方法的普遍现象——这才是有可能成为独立结论的东西。
- **止损线**：如果第二篇的复现就失败，或需要 CUDA 才能跑，就收尾写作，不再扩展。
