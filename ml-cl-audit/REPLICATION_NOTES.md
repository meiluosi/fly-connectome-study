# 复现记录：FlyModel（Shen, Dasgupta, Navlakha, arXiv 2107.07617）——写于运行之前，2026-10-05

## 复现目标（来自论文文本；从文本提取，未核对图表）
| 基准 | 指标 | 论文数字 |
|---|---|---|
| MNIST-20（10 任务×2 类） | FlyModel 学完 5 个任务（10 类）后的准确率 | 0.86 ± 0.0006 |
| MNIST-20 | FlyModel 最终准确率（20 类，稀疏编码+部分冻结） | 约 0.75（消融段）；比其他持续学习方法至少高 0.19；比离线上界低 0.11 |
| MNIST-20 | FlyModel 平均 memory loss | 0.07（EWC/GEM/BI-R 为 0.24/0.27/0.42 之类，顺序未核对） |
| CIFAR-100（25 任务×4 类） | FlyModel 最终准确率 | 约 0.41；比其他方法至少高 0.15；比离线上界低 0.13 |
**复现判据**：最终准确率偏差 ≤ 0.05，memory loss 偏差 ≤ 0.03，视为复现；超出则先查原因，查不出就如实记录"未复现"并停止（止损线）。

## 论文设定（我读到的）
- MNIST-20：MNIST（标签 0–9）+ FashionMNIST（标签 10–19），特征 = 在 KMNIST 上训练的 LeNet5（lr 0.001，batch 64，25 epoch，BN，Adam）的倒数第二层 84 维；CIFAR-100：ImageNet 预训练 ResNet18 倒数第二层 512 维。
- FlyModel：固定稀疏随机投影 Θ（MNIST-20 每个 KC 取 10 个输入，m=3200；CIFAR-100 每个 KC 取 64 个输入，m=20000）；k-WTA 保留最强 l=m/k 个（k=类数：20 或 100，即 5% 与 1%）；对 φ 做 min-max 归一化到 [0,1]；权重 w∈[0,1]；更新 `w_ij ← (1−α)w_ij+β·φ_i`（j 为目标类），α=0，β=0.01（MNIST-20）、0.2（CIFAR-100）。
- 类增量；每类的样本依次呈现，单遍训练；每个任务结束后在"已学过的类"上测试。memory loss = 任务刚学完时在该任务类上的准确率 − 全部任务学完后在该任务类上的准确率。

## 论文没说清、我必须做的选择（若复现失败，这些是首要怀疑对象）
1. **min-max 归一化**：解释为对每个样本的 φ 除以其最大值（因为 φ 的最小值是 0）。
2. **WTA 并列处理**：取 `argpartition`/`argsort` 的前 l 个，并列任意。
3. **预测**：在"已见过的类"上取 argmax（未见过的类不参与竞争）。
4. **特征提取**：LeNet5 结构为经典 conv(1→6,5)-BN-ReLU-pool-conv(6→16,5)-BN-ReLU-pool-fc120-fc84-fc10；ResNet18 的 CIFAR-100 输入采用**原生 32×32**（不放大），ImageNet 均值方差归一化。
5. **数据**：MNIST、FashionMNIST 使用标准训练/测试划分；KMNIST 仅用其训练集训练编码器。
6. **每个类内样本顺序**随机（种子控制）；论文中的随机种子数未读到，本复现用 5 个种子（0–4）。
7. 论文是 arXiv 2021 版，Neural Computation 2023 版可能有差异；本复现不核对后者。

# 附录 A（2026-10-05，在运行第二种特征之前写下）
**结果**：按登记的设定（原生 32×32 特征）复现：MNIST-20 在容差内（最终 0.7065 对 0.75；10 类 0.817 对 0.86；memory loss 0.089 对 0.07）；**CIFAR-100 最终 0.3395，论文约 0.41，偏差 −0.070，超过 0.05 的容差，按登记规则不算复现**。
**诊断**：在这套 32×32 特征上，离线线性分类器仅 0.4406（论文暗示的离线上界约 0.54），最近类均值 0.273，说明特征质量低于论文使用的特征。最可能的原因是论文把 CIFAR 图像放大后再输入 ImageNet 预训练的 ResNet18（论文没写）。
**拟采取的措施（先声明，再运行）**：新增特征变体 B——将 32×32 图像双线性放大到 224×224，其余不变（ImageNet 均值方差归一化，ResNet18 倒数第二层 512 维）。FlyModel 参数不变（m=20000，64 个输入/KC，l=200，β=0.2），5 个种子。
**判据不变**：变体 B 下的最终准确率与 0.41 的偏差 ≤ 0.05 才算复现。若变体 B 也不达标，如实记录"CIFAR-100 未复现"，不再调整 FlyModel 参数去凑数字。变体 A 与 B 的结果都会报告。
**说明**：这是看到 A 的结果之后做的修正，属于对复现设定的事后调整，已在此声明；它没有调整 FlyModel 本身的任何超参数。

# 附录 B（2026-10-05）：复现结论
| 基准 | 论文 | 复现 | 判定（容差 0.05） |
|---|---|---|---|
| MNIST-20 10 类时准确率 | 0.86 | 0.817 ± 0.003 | 在容差内 |
| MNIST-20 最终准确率 | 约 0.75 | 0.707 ± 0.004 | 在容差内 |
| MNIST-20 平均 memory loss | 0.07 | 0.089 ± 0.002 | 在容差内（容差 0.03） |
| CIFAR-100 最终准确率，变体 A（32×32 特征） | 约 0.41 | 0.340 ± 0.001 | **未复现**（−0.070） |
| CIFAR-100 最终准确率，变体 B（224×224 特征） | 约 0.41 | 0.508 ± 0.005 | **未复现**（+0.098） |
**结论**：MNIST-20 复现成功。CIFAR-100 数值上未复现：论文的数字夹在我的两种特征之间，说明它的特征处理介于二者之间（论文未说明），我无法确定。离线线性分类器在两种特征上的准确率为 0.441（A）与 0.683（B），论文暗示的离线上界约 0.54（但其"离线"是 MLP，不可直接比较）。
**决定**：不再调整 FlyModel 的参数去凑 CIFAR-100 数字（登记规则）。后续审计把 CIFAR-100-A 与 CIFAR-100-B 作为"弱特征/强特征"两个区间，**只做方法之间的相对比较**，并在报告里写明 CIFAR-100 的绝对数字与论文不可比；一个结论只有在 MNIST-20 与两个 CIFAR-100 区间里都成立，才称为稳健。
