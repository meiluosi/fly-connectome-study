# 预先登记：FlyModel 审计（写于运行任何审计实验之前，2026-10-05）

背景见 `PROPOSAL.md` 与 `REPLICATION_NOTES.md`（含附录 A、B）。复现状态：MNIST-20 复现成功；CIFAR-100 数值上未复现，作为两个特征区间使用（A：32×32 特征，弱；B：224×224 特征，强），**只做方法间相对比较**。

## 1. 设定（冻结）
- 三个基准：**MNIST-20**（84 维 LeNet5 特征，10 个任务×2 类）、**CIFAR-100-A**、**CIFAR-100-B**（512 维 ResNet18 特征，25 个任务×4 类）。类增量，类按自然顺序，每个类内样本顺序由种子打乱，单遍在线流为主设定。预测只在已见过的类上取 argmax。
- **验证集**：每个基准把训练集按类划出 10%（固定种子 12345）作为验证集，**所有超参数只在验证集上选**；测试集在最终评测前不使用。最终评测时用全部训练集重新训练。
- 种子：随机方法（FlyModel 的投影、网络初始化、回放缓冲区）用种子 0–4；确定性方法（原型类）只有一个值。区间用自助法（对种子）或在确定性方法上不给区间（只与随机方法的均值及区间比较）。
- 主要指标：**最终准确率**（全部类学完后在全部类上的测试准确率）。次要：学习时准确率 A_jj、memory loss（A_jj − 最终，对全部任务平均）、归一化遗忘（`clmetrics.py`）。

## 2. 方法与调参网格（均在验证集上以"最终准确率"选）
**FlyModel 家族**（`cl_bench.FlyModel`）
- F0：论文默认（MNIST-20：m=3200、10 输入/KC、l=160、β=0.01；CIFAR-100：m=20000、64 输入/KC、l=200、β=0.2）。
- F1：验证集调参版：l/m ∈ {1%, 2.5%, 5%, 10%}，β ∈ {0.01, 0.05, 0.2}（m 与输入数不变）。
- F2（无 WTA 的稠密对照）：同样的 Θ、不做 WTA，对 φ 做 L2 归一化；F2b：同上不做归一化（论文的"稠密编码"）。
**免回放原型/生成式基线（无反向传播）**
- P1：最近类均值（欧氏）。P2：最近类均值（余弦；特征与类均值 L2 归一化）。P3：原始特征上的类和点积（= 无扩展无 WTA 的 Hebbian 类和）。P4：SLDA（共享协方差的流式 LDA），收缩系数 ∈ {1e-3, 1e-2, 1e-1, 1}。
**反向传播基线**（架构同论文：输入 → 隐层（输入维数 ×40 个 ReLU 单元：MNIST-20 为 3200，CIFAR-100 为 20000）→ 输出；单遍在线，批大小 10）
- B1 Vanilla 微调：Adam，lr ∈ {1e-4, 1e-3, 1e-2}。
- B2 EWC：同 B1 的 lr 网格，λ ∈ {1, 10, 100, 1e3, 1e4}（对角经验 Fisher，每个任务后累加）。
- B3 回放（ER，蓄水池）：缓冲区 200 与 1000 样本；每步混入等量回放样本；lr 同 B1 网格。
- B4 离线上界：全部类联合训练（多遍，早停于验证集），仅作为最终准确率的上界。
- **多遍灵敏度**：B1–B3 额外在 5 遍设定下用同样网格调参，作为"论文设定可能对基线不利"的检验，单独报告。

## 3. 假设与判据（以最终准确率差为准；"优势"指 FlyModel 减对比方法）
- **H1（原型等价）**：对每个基准，令 best_P = max(P1, P2, P3, P4，各自按验证集调参) 的测试最终准确率。若 F0 的最终准确率均值 − best_P < 0.02 → 判"FlyModel 在该基准上没有超过免回放原型基线的实质优势"；若 ≥ 0.02 且 F0 的 5 个种子中位数高于 best_P → 判"FlyModel 超过原型基线"。三个基准都判前者 → 总判"原型等价成立（该结论稳健）"；三个都判后者 → "不成立"；其余 → "混合"。
- **H2（稀疏的价值）**：F0 − F2（稀疏 vs 稠密加归一化）的最终准确率差：≥ 0.02 且 5 个种子区间下界 > 0 → "WTA 稀疏有价值"；落在 ±0.02 内 → "无实质价值"。F0 − F2b 单独报告（论文的稠密对照）。
- **H3（公平调参）**：令 best_BP = 验证集调参后的 B1、B2、B3(200) 三者中测试最终准确率最高者（单遍设定）。F0 − best_BP ≥ 0.05（三个基准都成立）→ "论文关于优于 EWC/小缓冲回放的结论在公平调参下仍成立"；否则列出不成立的基准。B3(1000) 与多遍设定另行报告，不进入主判据。
- **H4（学习量视角，仅报告）**：每个方法的（A_jj，最终准确率，memory loss）三元组与归一化遗忘；以及"原型类方法的权重遗忘在构造上为 0"这一事实的验证（打乱类顺序后原型方法结果不变；FlyModel 结果与样本顺序无关）。

## 4. 实现验证（运行前必须通过，并记录）
- 单元/健全性测试：(a) 打乱类顺序后 P1–P3 与 FlyModel 的最终准确率不变（FlyModel 仅依赖 Θ）；(b) EWC 在 λ=0 时与 Vanilla 逐位相同；(c) 回放在缓冲区容量=全部数据时的最终准确率接近离线上界；(d) 合成可分数据上所有方法的准确率合理；(e) F2（无 WTA）在 l=m 时与 FlyModel 相同。
- 独立审查：全部结果产出后，起一个无上下文的 agent 审查实现与统计（泄漏测试集、空操作基线、指标退化），其发现写入 `verification/`，并据此更正。

## 5. 不做的事
不调整网格、阈值或判据；不为让 CIFAR-100 数字接近论文而改动 FlyModel；若出现实现缺陷，先写入 `DEVIATIONS.md` 再处理。若 B1–B3 在某基准上无法在合理时间内完成调参（>3 小时），如实报告该基准的缺失而不是缩水网格。

## 6. 已知局限（预先声明）
- 与论文的基线实现（GEM、BI-R）不同：本审计不含 GEM 与 BI-R（GEM 需要梯度投影，BI-R 需要生成模型）；ER 作为带小缓冲区的代表。
- CIFAR-100 的特征与论文不同，只能作相对比较。
- 单一特征提取器（LeNet5 一次训练；ResNet18 预训练），所有结论只对这些特征成立。
- 区间只反映种子方差，不反映特征提取器、类顺序、数据划分的方差。
