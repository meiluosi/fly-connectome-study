# 提案：FlyModel 的"低遗忘"是蘑菇体启发的功劳，还是类原型分类器的结构性质？

状态：草案，等待你对下载的批准；运行任何实验前会先写预先登记并记录哈希。

## 1. 问题（比最初的"匹配学习量"更具体）
Shen、Dasgupta、Navlakha（FlyModel，arXiv 2107.07617；Neural Computation 2023）报告：固定的稀疏随机投影 + 取最强 5% 的 KC（k-WTA）+ "只更新目标 MBON 的权重"，在类增量学习里大幅减少遗忘，优于 EWC、GEM、BI-R。

我从论文原文读到的事实（2021 版 arXiv，NeCo 版可能有差异）：
- 更新规则：`w_ij ← (1−α)w_ij + β·φ_i`（j 为目标类），其余权重只衰减，实验中 α=0。因此**每个类的权重向量就是该类稀疏特征的累加和**，是随机稀疏特征上的类原型（无归一化）分类器。
- 基准：MNIST-20（MNIST+FashionMNIST，10 个任务×2 类，特征来自在 KMNIST 上训练的 LeNet5，84 维）与 CIFAR-100（25 个任务×4 类，特征来自 ImageNet 预训练 ResNet18，512 维）；类增量，单遍训练。
- 对手：EWC、GEM、BI-R、普通网络、离线上界，全部用反向传播、同架构（84→3200→20 的 ReLU 网络等）。**没有"同样特征上的最近类均值（NCM）/SLDA/岭回归"这类免回放原型基线。**
- 超参数："对每个模型和数据集用网格搜索最大化准确率"；我读到的部分没有说明独立验证集。
- 度量：随任务推进的已学类准确率，以及 memory loss（= 刚学完时的任务准确率 − 最终准确率）。

**要检验的假设**
- **H1（原型等价）**：在同样的冻结特征上，NCM / 类均值余弦 / SLDA 等**无反向传播的原型基线**，能达到或超过 FlyModel 的最终准确率，因而"仿果蝇"在这些基准上没有增量价值。
- **H2（稀疏扩展的价值）**：把 FlyModel 里的稀疏扩展 + k-WTA 去掉（换成同样特征上的原型分类器，并做正确的归一化），准确率不降，则稀疏扩展的作用被论文里"稠密编码只有 0.07"的对照夸大了（那个对照可能是一个范数偏置问题，需要检验，而不是预设）。
- **H3（调参公平）**：给反向传播基线与 FlyModel 同样规模、在**独立验证集**上做的调参，并允许多遍训练，结论是否改变。
- **H4（学习量）**：按匹配学习量/稳定性–可塑性前沿报告，遗忘的差异是否仍在。注意类增量里 FlyModel 的"遗忘"部分是结构性的（各类权重互相独立），所以这一条可能是平凡的，需要在报告里分清"权重遗忘"与"决策竞争导致的准确率下降"。

## 2. 新颖性与定位（诚实版）
- 调研（`survey/literature.md`，约 70% 置信度）：**匹配可塑性/前沿比较的原则已有**（RWalk 2018；Michel 2023；Cha & Cho 2025；Pareto CL 2025），但**没有找到系统复核果蝇/稀疏编码类 CL 方法的工作**。检索有局限（只有网页搜索，PDF 多数读不出，2026 年预印本索引弱），动手前还应查 Semantic Scholar / Google Scholar。
- 因此贡献应定位为：**一份实证审计 + 一套可复用协议**，不是新原理。
- 可能的结果：(a) 复核后结论基本成立（也是有价值的确认）；(b) 被简单基线追平；(c) 部分成立。**三种结果我都需要如实报告**。

## 3. 协议（避免上一个项目犯过的错）
1. 先复现论文的数字（MNIST-20、CIFAR-100），复现不了就先停，如实记录。
2. 所有方法同一套特征、同一任务顺序、同一随机种子集；至少 5 个种子并报告区间。
3. 超参数**在独立验证集上**调（例如用从训练集切出的验证类/样本；不碰测试集），各方法同样的调参预算，并预先登记网格。
4. 报告：学习准确率 A_jj、最终准确率、遗忘、归一化遗忘、已学类准确率曲线；对有可调"可塑性旋钮"的方法，报告稳定性–可塑性前沿并在匹配学习量处比较（`clmetrics.py` 已含这部分且有合成数据单元测试）。
5. **实现必须独立审查**：起一个无上下文的 agent 审查实现与统计，特别查：基线是否空操作、是否泄漏测试集、指标是否有退化（这是上一个项目里审查抓到的错误类型）。
6. 每一步先写预先登记并记录哈希，偏离单独记录。

## 4. 候选基线（均免回放、无反向传播或轻量）
FlyModel（按论文自行实现，第三方端口 Ramos-Ramos/FlyModel 仅作交叉检验）；NCM（欧氏/余弦）；SLDA（共享协方差的流式 LDA）；岭回归/RanPAC 式随机特征 + 岭；反向传播基线：微调、EWC、小缓冲区回放（200/1000）、离线上界。FlyPrompt（ICLR 2026）与 Fly-CL（ICLR 2026，官方代码、冻结骨干 + 果蝇式头）作为**第二阶段**，需要更重的环境与数据。
