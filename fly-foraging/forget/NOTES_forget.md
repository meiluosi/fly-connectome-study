# 遗忘检验（forget）：解读

登记：PREREG_forget.md（哈希见 PREREG_forget.sha256）；结果：RESULTS_forget.md（自动生成）。100 个新世界（6000–6099），三种条件，22 个配置，共 6600 次运行；这是对一个事后解释的检验，不是新的预先设想的假设。

## 结果
- **遗忘在波动的世界里有益，在稳定的世界里有害。** fast（反转周期 500）：decay 3e-3 / 1e-2 把净奖励从 +5.2 提到 +17.4 / +17.7（+12.1 [+9.9,+14.4]；+12.4 [+9.8,+15.0]）。in-dist：1e-3 / 3e-3 提升 +10.2 / +9.4。stationary：1e-3 掉 12.8，1e-2 掉 40.7，3e-2 掉 54.8。
- 主结论族（登记）：fast 下 decay=1e-2 对 0 → 更好；decay=1e-3 对 0 → +3.5 [+1.6,+5.4]，区间不含 0 但低于 ±4 的界限，判“不确定”。
- 在 3 个进化结果上强制加遗忘：同一模式（fast +9 到 +14 @1e-2；in-dist +8 到 +10 @1e-3；stationary −13 @1e-3）。进化结果加 1e-3 遗忘后，in-dist 比手调默认高 +12 到 +16，超过了进化自己找到的 +4 到 +7。
- 学习速度：0.25 倍在三种条件都明显更差；2 倍、4 倍没有额外好处（fast：−0.2 / −1.2，等价）。交互项 +2.5 [−2.8,+8.2]，不确定。
- 不对称：(0.4,0.8)、(0.8,0.4)、(0.4,1.6) 在 fast 与对称等价，在 stationary 更差或不确定。进化选出的 neg>pos 没有被单独支持。

## 为什么进化没有找到遗忘（诊断；已由 meta2 重跑证实）
`forage2.decode`：decay = 10^(−5 + 3.5·sigmoid(θ))；`encode` 对 decay=0 给出 θ=−6，落在 sigmoid 平坦尾部（起点 decay≈1.0e-5，d decay/dθ≈2e-7）。要到 decay=1e-3 需要 θ≈+0.29，离起点 6.3；进化步长 σ=0.4。起点附近候选之间的奖励差异几乎为零，所以没有梯度信号。因此“9 次进化全部停在下界”是参数化造成的，不是“进化发现遗忘无用”。
