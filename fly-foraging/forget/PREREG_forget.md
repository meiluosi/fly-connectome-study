# 预先登记：进化为什么没有选择“遗忘”？（元学习的后续检验）

写于运行之前。冻结文件与哈希：`PREREG_forget.sha256`。没有调参步骤（所有配置在下面列出，直接评估）。

## 问题
元学习里 9 次进化的遗忘速率全部停在搜索范围下界（1e-5）。两种可能：(a) 在这些世界里不遗忘确实最好；(b) 这是搜索的假象（梯度弱、范围、进化步数）。另外我对 (a) 给过一个事后解释：反转世界里“学得快”比“遗忘”重要，负预测误差本来就能压掉旧价值。这里直接检验。

## 设计
- 回路：真实连线（`forage.F.P0`）；学习器 `forage2.run_fly2`；运动常数同前（k_turn=1.4，g_inn=0.3）。
- 世界：种子 6000–6099（100 个，从未用于调参、进化或评估），三种条件：fast（反转周期 500）、indist（反转周期 [1000,2000,3000][s%3]）、stationary（不反转）；冲突/一致按 s%2 交替；T=6000；果蝇种子 9000+s。
- 指标：6000 步总净奖励；配对差（同世界同果蝇种子）；对世界做 4000 次自助法。
- 基准配置 B：手调默认 (eta_pos=0.4, eta_neg=0.4, decay=0, kc_frac=0.05, g_learn=2.0)。
- 配置：
  1. 遗忘扫描（其余同 B）：decay ∈ {0, 1e-4, 1e-3, 3e-3, 1e-2, 3e-2}（每 tick 向初值回落的比例）。
  2. 学习速度（decay=0）：两个学习率同乘 {0.25, 0.5, 1(=B), 2, 4}。
  3. 不对称（decay=0）：(pos,neg) ∈ {(0.4,0.8), (0.8,0.4), (0.4,1.6)}。
  4. 进化结果上强制遗忘：真实连线的 3 个进化结果（`evo_real_{0,1,2}.json` 的 final_prm），decay 分别取原值（≈1e-5）、1e-3、1e-2，其余参数用进化值。
- 判定：等价边界 ±4 净奖励（约为默认果蝇平均净奖励的 10%）；规则同 v2（区间整体在 ±4 内=等价；区间不含 0 且均值≥4=A 更好/更差；否则不确定）。
- **主结论（2 个对比，用 97.5% 区间）**：fast 条件下，decay=1e-3 对 decay=0，以及 decay=1e-2 对 decay=0。其余均为描述性（95% 区间）。

## 预测（不是判据）
- 遗忘不帮忙：所有 decay>0 在三种条件下都不优于 decay=0，更大的 decay 变差（尤其 stationary）。
- 学习更快在 fast 里受益最大，stationary 里受益小或为负。
- 不对称（neg 更快）略好于对称，但幅度不大。
- 进化结果上强制遗忘不改善。
若以上任何一条被推翻，如实写进结果。

只有真实连线与一组默认/进化参数；100 个世界对 ±4 的边界是否足够，见 `verdict` 的半宽警告；这是对一个事后解释的检验，不是新的预先设想的假设。
