# 提案：蘑菇体学习者在非平稳"气味觅食"里的泛化——真实连线有用吗？（草案，等待确认）

状态：调研完成，基线库已建并通过测试；尚未写预先登记，尚未做任何对比实验。

## 1. 调研结论（`survey/bennett_review.md`，agent 读了约 100k/139k 字符的全文，引文经摘要工具，引用前需核对原文）
- **Bennett、Philippides、Nowotny（Nat Commun 2021）已经把蘑菇体建成赌博机学习者**：速率模型，每个线索 10 个互不重叠的 KC，两个输出神经元（趋近/回避），多巴胺神经元编码强化预测误差，学习规则是 delta 规则，softmax 选择，臂数 2 到 200。测过奖励均值的阶跃和滤波噪声变化，**没有**命名的反转学习，**没有**和 Q-learning / UCB / Thompson 等标准算法的对比，唯一的对照是"完美可塑性"模型。代码是 MATLAB（GPL-3.0），核心只有几行，适合自己用 Python 重写。
- 相邻工作：Danieli & Lepperød 2025（[arXiv 2509.22209](https://arxiv.org/abs/2509.22209)）用一个**皮层启发**的极小模型做非平稳 K 臂赌博机，并与 Thompson 采样、UCB 对比，不是蘑菇体；Springer & Nawrot 2021（消退学习的机制模型）。
- **没有找到**把蘑菇体模型与赌博机算法或蚁群算法做匹配预算对比的工作（agent 与我的检索都只用网页搜索，置信度约 75%）。

## 2. 调研暴露的三个风险（原样保留）
1. **"只是一个 delta 规则"**：单热码 KC 下，这个学习者本质上是常数步长的 Q 学习器，大概率只和折扣 ε-贪心相当，输给折扣 UCB / 滑窗 UCB / Thompson。我的基线库调参结果已经显示这一点：折扣 UCB 的遗憾（222）远低于常数步长 ε-贪心（313）和蚁群式信息素（488）。
2. **稀疏扩展只有在有结构时才有用**：独立臂下 KC 扩展无关紧要，需要相关臂、带上下文的臂，或有噪声的线索识别。
3. **不公平或不明确的比较**：softmax 的 β、λ 在论文里未给出或不一致；必须统一调参预算；蚁群式信息素基线近似于折扣价值跟踪器。

## 3. 因此我建议把问题重新定义（这是和之前说的"蘑菇体 vs 蚁群"不同的地方）
**独立臂的赌博机里，蘑菇体的结构没有用武之地；要让它有用，就必须有"气味相似则奖励相似"的泛化需求。**

**问题**：在一个**奖励随时间漂移、气味之间有重叠**的觅食任务里，
(a) 蘑菇体式学习者（真实的 PN→KC 连线 + 稀疏编码 + 多巴胺门控的 delta 规则）是否优于**不能泛化**的方法（表格型赌博机、蚁群式信息素）？
(b) 它是否优于**线性上下文赌博机**（LinUCB / 线性 Thompson，带遗忘）？
(c) **真实的连接组连线是否比随机稀疏扩展、打乱的连线更好？**（这是真正新的问题；前面的证据倾向于"否"。）

**环境**：气味 = 65 个小球里的 6 个（沿用已有的 MaleCNS PN→KC 连线与 2045 个 KC）。一个有限的气味目录（如 200 个），每步随机提供其中 8 个让智能体选一个，伯努利奖励。奖励函数两类：**线性**（对某些小球加权，权重随机游走）与**合取型**（含有某一对小球的气味有奖励，且该对随时间切换）。后者需要非线性，线性基线会吃亏。

**智能体**
- 蘑菇体学习者：(M1) 真实 PN→KC 连线 + top-5% + 真实 KC→MBON 连线与递质符号（沿用上个项目的行为读出）+ 多巴胺门控的 delta 规则；(M2) 打乱（保度数）的 PN→KC 连线；(M3) 随机稀疏连线（每个 KC 取 6 个输入）；(M4) 无 WTA 的稠密扩展；(M5) 无学习。
- 基线：随机；表格型 ε-贪心 / UCB / 折扣 UCB / Thompson / 折扣 Thompson / 蚁群式信息素（按气味 ID，无泛化）；**线性上下文**（线性 Thompson、LinUCB，带遗忘因子）；**同样特征上的贝叶斯线性头**（随机稀疏扩展 + 线性 Thompson，即"有扩展但不是蘑菇体学习规则"）。

**协议（沿用之前的教训）**
- **调参环境与测试环境分开**（不同种子与漂移速率），所有方法同样的调参预算，网格预先登记；
- 同一实现的随机数共享（`bandits.py` 里奖励用预抽的均匀数，保证配对）；30 个种子，配对自助法区间；
- 预先登记假设与等价边界，**运行前锁哈希**；
- 实现之后起一个无上下文的 agent 审查（泄漏、空操作基线、指标）；
- 指标：累计伪遗憾（相对每步提供的最佳气味）。

**预期假设（待登记）**
- H1：M1 优于所有"不能泛化"的方法；
- H2：M1 与 M3（随机稀疏连线）在等价边界内无差异（这是我认为最可能的结果）；
- H3：线性奖励下 M1 不优于线性上下文基线；合取型奖励下 M1 优于线性基线，但不优于"随机稀疏扩展 + 线性 Thompson"；
- H4：稀疏优于稠密。

## 4. 诚实的预期与止损
- 最可能的结果：蘑菇体学习者优于不能泛化的方法，但与随机稀疏扩展、以及"随机特征 + 线性头"无差异；即**真实连线没有额外作用**。这与上个项目、flybench 的结论一致。即便如此，这个比较（带调参协议与审查）是干净的，且不依赖玩具回路。
- 止损：如果 M1 连"不能泛化"的基线都不如（H1 不成立），或者基线库在调参后已经很强到比较没有意义，就收尾写作，不再扩展。
- 范围：全部在速率域，不使用 LIF 引擎（太慢）；蚁群式信息素只作为基线之一，不作为主角。
